# 停车场管理数据库项目最终检查报告

审查日期：2026-10-24

## 一、结论

需求模型、字段设计、建库脚本、查询说明和项目报告已形成对应的静态设计材料。项目报告正文包含六个核心查询的 MySQL Workbench 截图及结果集；封面也已填写成员姓名和学号。本次检查据此修正了文档中“查询截图缺失”和“封面信息未填”的过期结论。

项目仍有未完成的验收项：没有完整初始化脚本执行成功记录或约束负例验证证据；图稿未满足清单中的完整属性标注要求；跨记录约束未在脚本中实现；报告仍有分页问题，封面信息也需小组核准。

## 二、审查范围与边界

检查对象包括 README、实施计划、任务清单、需求与数据库模型、SQL 字段/查询/命名说明、建库脚本、draw.io 图稿和项目报告 DOCX。静态检查可比较命名、字段、约束说明和 SQL 文本，但本次没有连接 MySQL 实例执行初始化脚本或约束负例。报告内六个查询截图作为现有证据核对；不据此推断完整建库流程或约束测试均已通过。

项目报告经 DOCX 渲染得到 15 页，封面后正文页脚连续编号 1–14。渲染未显示页码在末页重置；发现表格跨页、表 2-6 标题与表体分离等遗留分页问题。报告图像中的查询 SQL、结果集和 Workbench 执行输出可见，但截图缩放较小，提交前应确认可读性。

## 三、已确认并同步的内容

- 项目范围为单个停车场，包含车主、车辆、车位、停车记录、收费规则、月租合同、缴费记录和管理员 8 张业务表。
- 数据库对象名采用英文 `snake_case`；中文业务概念与英文物理名称通过《../sql/中英文命名映射.md》对应。
- SQL 脚本包含 8 张表、样例数据、3 个单表查询、3 个多表查询及 5 个统计查询。查询说明将首个多表查询归为四表连接，与 SQL 的主表加 3 次 JOIN 一致。
- 报告图 1-3 至图 1-8 包含六个核心查询的 Workbench 截图及结果集；任务清单现将查询截图任务标为完成。
- 报告封面已有成员姓名和学号。任务清单将其状态改为待核验，要求小组按正式名单确认信息与格式。
- 外键更新动作与字段设计说明、SQL 一致：参与互斥 CHECK 的 4 个外键列使用 `ON UPDATE RESTRICT`，其余使用 `ON UPDATE CASCADE`；历史记录使用 `ON DELETE RESTRICT`。
- 停车记录状态与出场时间/停车时长的组合已在模型与 SQL 中说明；异常状态的字段组合仍未限定。
- 同车/同车位最多一条未出场记录、同车生效合同日期不重叠及停车流程与车位状态联动属于跨记录规则。模型和 SQL 均注明当前脚本未实现，需由事务、触发器或应用服务承担。

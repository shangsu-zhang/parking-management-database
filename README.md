# 停车场管理数据库项目

这是一个面向单个停车场的数据库课程项目，覆盖车主、车辆、车位、停车记录、收费规则、月租合同、缴费记录和管理员 8 个核心实体。项目使用 MySQL 8.0 设计，脚本和文档中的表名、字段名、约束名统一采用英文 `snake_case`。

## 项目内容

- `sql/停车场管理数据库.sql`：建库、建表、约束、样例数据和查询脚本。脚本会重建 `parking_management_db` 及其 8 张业务表。
- `sql/查询说明.md`：11 个查询的用途、SQL 和预期结果，其中 3 个单表查询、3 个多表查询属于课程核心案例。
- `sql/字段设计说明.md`：字段类型、空值、默认值、主外键、检查约束和索引说明。
- `sql/中英文命名映射.md`：中文业务名称与英文物理名称的对应关系。
- `01_需求与数据库模型.md`：需求、实体属性、联系基数、关系模式、规范化和一致性校验说明。
- `02_实体属性图.drawio`、`03_整体ER图.drawio`：可编辑图源；同名 `.png` 为报告插图。
- `停车场管理项目报告.docx`：课程项目报告。
- `项目实施计划.md`、`任务清单.md`、`最终检查报告.md`：计划、验收清单和已知问题记录。

## 使用方式

需要 MySQL 8.0.16 或更高版本（推荐 8.0.30+）。在 disposable 或专用项目数据库中执行：

```sh
mysql --default-character-set=utf8mb4 -u <user> -p < sql/停车场管理数据库.sql
```

脚本会删除并重建项目表，请确认目标数据库中没有需要保留的数据。执行后可按 `sql/查询说明.md` 验证查询；脚本末尾的注释负例可用于检查唯一键、CHECK 和外键约束。
